# デイリー役割表

「デイリー役割表」メニューで開始日を選び、1日または7日間を表示します。
職員・勤務記号・実際の配置先は既存のシフトデータから読み込みます。
担当可能フロアで職員を絞り込めます。複数フロアの職員は勤務記号下の実配置先を確認してください。

AM／PMの枠を押して担当を選択、または直接入力し「保存」します。
「担当項目の編集」で候補を1行ずつ追加・変更できます。
候補を変えても、過去に保存した役割の文言は書き換わりません。
BB・Lは写真を参考にした候補名であり、資格や配置ルールを自動的に意味するものではありません。

勤務区分の開始・終了時刻で、12時より前をAM、12時以降をPMとして担当可能か判定します。
休み・有休・明け・未入力・夜勤には日中の担当を登録できません。
夜勤は既存の配置先または兼務リーダーをPM欄へ表示します。
今回の機能はシフトから対象者を読み込んで手動で役割を割り当てる機能です。
役割の自動配分、職員別の役割適性・必要人数の判定は行いません。

勤務種別・勤務時間・配置先が変わった場合、保存済み担当を残して「要確認」と表示します。
担当を開き、現在の勤務に合わせて保存し直すか「担当をすべて解除」してください。
再生成による一時的なシフト削除でも役割を消去しません。職員そのものを削除すると関連する役割も削除されます。
別の画面から同じ枠が更新された場合は競合を通知し、古い内容で上書きしません。

A4横／A3横で印刷・PDF出力できます。印刷直前に最新情報を読み込みます。
要確認がある間は画面の印刷ボタンを無効にします。未入力の担当枠は印刷では空欄です。
人数や文字量が多い場合は複数ページになり、各ページに日付見出しを繰り返します。

新規テーブル daily_duties・daily_duty_options は起動時に作成されます。
既存SQLiteバックアップには両テーブルも含まれます。
管理者を設定済みの環境では、画面・APIとも管理者ログインが必要です。
管理者未設定時の開放モードは既存アプリの方針に従います。
